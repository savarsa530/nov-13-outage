    Dispute tracker (claims vs. evidence)
    

    Each claim set against what the public record actually supports, who holds which position, and what would settle it. When a denial is quoted, the record line says what it denies: the command path or the network path. The first seven cards are the live disputes; the rest are carried over from v2.0.
    

    

    Claims that rule things out are firmer than claims that assign cause. Early in an incident that can be innocent: ruling things out is fast, and assigning cause takes an investigation. Recheck when the FAA publishes preliminary findings.
